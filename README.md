# about
in order to practice more javascript, i made a music player with some songs i like! hover over the player to focus. press the play button, or previous/next buttons to change the song. 
this was developed using html, css, and javascript on vscode. i'm also submitting this to hackclub's athena award! [![Athena Award Badge](https://img.shields.io/endpoint?url=https%3A%2F%2Faward.athena.hackclub.com%2Fapi%2Fbadge)](https://award.athena.hackclub.com?utm_source=readme)
